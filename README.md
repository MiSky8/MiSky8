# Hi, I'm Ali 👋

I build AI assistants and agents that work on a company's own data — email,
documents, databases and spreadsheets — so a team gets answers out of what it
already has. Models run through an API or locally, depending on how sensitive
the data is. I run [Algority](https://algority.pl) in Wrocław, Poland.

## What I'm working on
- **[ocrHub](https://github.com/MiSky8/ocrHUB)**: one Docker image with several
  OCR engines (Tesseract, pdfplumber, Surya, Datalab) that you can compare side
  by side, with an API and an MCP tool. I built it to share what I've learned
  and to make OCR decisions quicker for anyone exploring AI automation.
- **[Lunch Now](https://lunch.onl)**: an interactive map of lunch places,
  starting in Wrocław.

## Writing and teaching
- [Notes](https://algority.pl/notes/): technical articles on OCR, document
  pipelines and agents, in English and Polish.
- Guest lectures on AI, product thinking and building in a modern tech stack at
  [WSKZ](https://studia-online.pl/kadra/0/1417/mgr_alina_binkowska).

## Background
Master of Mathematics (Computer Science), University of Lodz. Sixteen years in
IT operations and delivery management, then my own company since 2022. Machine
Learning DevOps Engineer and Deep Learning nanodegrees (Udacity). Now I build AI
systems hands-on: document pipelines, agents and automations in Python.
